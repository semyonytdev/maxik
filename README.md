# maxik (Макс-предметы) 🐧

Fabric-мод для Minecraft 1.21.11. Все предметы чёрные (текстуры незерита, перекрашенные).

Получить: творческое меню (вкладки «Боевые» и «Инструменты») или команды `/give @s maxik:max_sword` и т. д.

| Предмет | Что делает |
|---|---|
| `max_sword` | 38 урона (19 сердец) |
| `max_pickaxe`, `max_axe`, `max_shovel`, `max_hoe` | мгновенно ломают любой блок, даже бедрок |
| `max_helmet` / `max_chestplate` / `max_leggings` / `max_boots` | защита 60 / 90 / 76 / 28 и дополнительное снижение урона |
| `max_totem` | в хотбаре или руке: +20 сердец. При смерти воскрешает (не тратится), чёрные частицы, 10 минут полной защиты, спасает от бездны и `/kill` |
| `max_end_crystal` | ставится на любой блок, взрыв снимает 60 здоровья |

Броня: в Майнкрафте показатель брони выше 30 не работает, поэтому мод ещё и сам уменьшает урон
(множитель `100 / (100 + сумма очков)`, полный комплект даёт 254 очка).

Сборка идёт на GitHub Actions: jar лежит в Releases.
